## Release gate

This is a substantial V2 implementation and local demo candidate, **not a production-ready or fully accepted release**. In particular, do not use real customer data or operational decisions. Complete the pending and partial requirements above—especially MySQL deployment, browser/accessibility verification, automated graduated safe-mode behavior, periodic tamper checks, effective-dated appliance calculations, and the optional LLM evaluation—before claiming full Brief v11 acceptance.
